Connect the Pocket over Bluetooth
  1. On the Pocket, use a model with the internal module set to CRSF / ExpressLRS.
  2. Press SYS, open ExpressLRS, scroll to [BLE Joystick] and press Enter.
  3. On the computer, pair “ExpressLRS Joystick” in Bluetooth settings.
  4. Come back, move a stick, then open the Controls tab and choose Set up controls.
Let a friend fly with their phone
  1. On this screen, open the Controls tab and choose Show pairing code.
  2. On the phone: scan the code with the camera and open it in Chrome or Safari, or open this site and add #pad to the address, then type the code.
  3. Pick Angle (easy), tap FLY, push the left stick up.

Or open the site on the phone itself: on-screen sticks appear automatically. To install it as an app, use Chrome's install icon (or Add to Home screen on a phone).
