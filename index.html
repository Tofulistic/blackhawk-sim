How to connect the Pocket over Bluetooth
  1. On the Pocket, make or pick a sim model with the internal module set to CRSF / ExpressLRS.
  2. Press SYS, open the ExpressLRS tool, scroll to [BLE Joystick] and press Enter.
  3. On your computer, pair “ExpressLRS Joystick” in Bluetooth settings.
  4. Come back here, move a stick, then open Controller setup to map your sticks and arm switch.
Use Chrome or Edge. A USB cable in joystick mode works too. No radio? Keyboard: W/S throttle, A/D yaw, arrows pitch/roll, Space arm, R reset.
Let a friend fly with their phone

Play on the phone: open this site on the phone and on-screen sticks appear automatically. Turn it sideways, tap Full screen, pick Angle / Gyro (recommended for beginners) or Air mode, then Fly.

Phone as the controller for this computer: install a "phone as gamepad" app that makes the computer see an Xbox controller (for example Remote Gamepad, or the free VGamepadWeb), pair it using the app's own steps, then move a stick here. Left stick = climb + turn (centre holds height in Angle mode), right stick = tilt, Y = reset.

Install as an app: in Chrome, use the install icon in the address bar (or menu ▸ Add to Home screen on a phone).
